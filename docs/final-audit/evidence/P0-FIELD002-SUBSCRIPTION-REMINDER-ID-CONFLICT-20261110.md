# P0 FIELD002 — Subscription reminder global-ID conflict must not falsely mark sent

**Date:** 2026-11-10. **Gate:** P0-RESIDUAL-MERCHANT-PRIVACY-001/http and FIELD002 remain OPEN. **Source-only fix**; no hosted provider identity, migration or production delivery approval.

## Real source gap

`refreshSubscriptionNotificationsPostgres` uses deterministic notification IDs for subscription expiry, subscription expired and addon-batch expiry. Its helper `insertMerchantNotification` used `INSERT ... ON CONFLICT(id) DO NOTHING` then unconditionally updated the subscription or batch `*_reminder_sent_at` flag. A synthetic conflicting global notification ID that **belongs to a different merchant, audience or source event** would cause the new merchant notification to be silently skipped while marking the reminder as sent. Existing database uniqueness and tenant RLS alone cannot establish the identity of the row that caused a conflict. A source identifier collision is not proved publicly exploitable; this is a fail-closed integrity guarantee under corruption, unusual restoration and privileged synthetic fixture scenarios.

[Production source fix `312f9286`](https://github.com/nora953/fawri-production-source/commit/312f9286309a8e96fcc9fc6531297e0a4c4fe499) converts the insert to `INSERT ... ON CONFLICT(id) DO NOTHING RETURNING id`, accepting actual new insert success. On deduplication, the existing row must be visible to the merchant-scoped SQL lease and match **merchant audience, merchant ID, correct account ID, notification type, title/body keys, source entity type and source entity ID**. Only this exact row permits the existing `*_sent_at` update without rewriting its prior stored fields. Missing, foreign, malformed or unrelated source identity throws `NOTIFICATION_SOURCE_ID_CONFLICT` (409), rolling back the entire scoped transaction and all associated sent markers and notifications. This applies to the existing 3 subscription reminder categories without adding new notification types or authorizing historical legacy notification writers.
