## Problem and bounded remediation

Under 0037, a tenant SQL role with audit-table INSERT/UPDATE could manufacture a live record with its own txid_current() and arbitrary admin GUCs. The transaction binding prevented committed-token replay but did not authenticate an issuer. This increment makes the non-PUBLIC EXECUTE ACL of `public.fawri_issue_admin_directory_audit(text,text,text)` a separately granted operator capability. The RLS predicate independently checks that ACL on the original `session_user`. Definer `current_user`, forged actor IDs, audit rows, expiry/transaction fields and custom GUCs do not replace the authenticated operator capability. An ordinary runtime must never inherit or SET ROLE into a capability/owner role.

Migration 0038 creates the bounded issuer with fixed pg_catalog search_path, validates bounded IDs/hash, checks active/enabled/non-password-change administrator identity, and accepts owner_admin or any of the five existing merchant-directory route permissions. It holds account/profile/permission SHARE locks, creates one one-minute audit in the issuing transaction and sets only local admin context. PUBLIC receives no issuer EXECUTE. No LOGIN, hosted grants, role memberships or production changes are provisioned. Manual SQL, canonical stage, snapshot and journal are committed; schema validation must prove reproduction/application.

The directory service no longer INSERTs audits directly. It calls the issuer and reads the existing directory in that transaction through `operatorDirectoryPostgresAuthority.ts`. Production requires `FAWRI_OPERATOR_DATABASE_URL`; it cannot fall back to tenant credentials. Server configuration alone selects credentials; request fields cannot select a pool. Dedicated connections must authenticate directly as the active role, hold issuer EXECUTE and have no SUPERUSER/BYPASSRLS/CREATEROLE, privileged inherited/SET-reachable role, public table owner or issuer owner authority. Connections are bounded to three and use the typed DB factory/shared sanitized driver error handling. Unit tests verify rejection before work, rollback/release, cache/config change handling and explicit close.

Non-production uses the existing operational pool only when no dedicated URL is configured and the release gate is off. SQL still requires issuer EXECUTE; application environment flags do not manufacture database privilege. Production tenant readiness rejects a missing issuer migration, effective issuer privilege on the current/session role or an inherited/SET-reachable role, and absent/invalid operator configuration. Dedicated operator connectivity/identity is checked on its actual transaction; a syntactically valid URL alone is not hosted operator certification.
