# Disposable PostgreSQL integration execution gate

Status: PLAN ONLY — NOT EXECUTED. Applies to PR #520 audit; main remains unchanged.

## Preflight, mandatory
1. Provision a new isolated PostgreSQL instance owned by this test run (CI service container or ephemeral Docker), with no Neon/Railway tunnel, proxy, remote database or production credentials.
2. Generate an ephemeral database and role. Record the container ID, local port, database name and a sanitized `SELECT current_database(), current_user, inet_server_addr()` result; never publish passwords.
3. Ensure the runtime cannot reach staging or production databases; use a network-restricted runner and a fresh DATABASE_URL generated by the job. Do not trust hostname `localhost` alone.
4. Apply the migrations from the exact reviewed main commit to the empty database. Verify schema and RLS policies before tests.
5. Enforce fail-closed environment checks before any test module imports or DB pool construction. Refuse absent/mismatched database name, role, run marker or container identity.
6. Stop immediately on unexpected connection target, mutation outside fixtures, or a failed safety assertion.

For each suite record exact source SHA, runner/job link, sanitized command, start/end, pass/fail/skip counts, failing assertions and issue ID.
